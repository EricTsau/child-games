## 🎮 馬上玩

**👉 <https://erictsau.github.io/-/>**

用手機或平板打開後，可以選「加到主畫面」，之後點圖示就能直接玩。

## 放到 GitHub Pages

1. 把這個專案推到 GitHub。
2. 到 repository 的 **Settings → Pages**。
3. **Source** 選 **Deploy from a branch**，Branch 選 `main`（或你的分支）和 `/ (root)`，按 **Save**。
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`（本專案為 <https://erictsau.github.io/-/>）。

## 在自己電腦上玩

直接用瀏覽器打開 `index.html` 就可以玩。如果想模擬網站環境，可以在資料夾裡執行：

```bash
python3 -m http.server 8000
```

然後打開 <http://localhost:8000>。

## 檔案結構

```
index.html            遊戲首頁
assets/common.css     共用樣式（按鈕、結算畫面、動畫）
assets/common.js      共用功能（音效、語音、彩帶、最高分）
assets/thumbs/        首頁用的遊戲截圖
games/<遊戲>/index.html  每個遊戲一個檔案
```

所有角色、道具和場景都是用 Canvas 和 SVG 手繪的向量圖，音效和背景音樂用 Web Audio 即時合成，沒有任何外部檔案。

每個遊戲都有標題畫面、多個關卡、1～3 顆星評分（存在瀏覽器裡），收集星星可以解鎖新角色、造型或場景。
