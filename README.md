# 🎠 小朋友遊戲樂園

82 個好玩的網頁遊戲（大部分為小朋友設計）。全部是純 HTML / CSS / JavaScript，不用安裝、不用網路資源，手機、平板、電腦都能玩。

## 🎮 馬上玩

**👉 <https://erictsau.github.io/child-games/>**

用手機或平板打開後，可以選「加到主畫面」，之後點圖示就能直接玩。

## 📲 安裝成 App

首頁有「安裝成 App」按鈕（網站是 PWA，可安裝的網頁 App）：

- **Android（Chrome）**：按下按鈕 →「安裝」，App 抽屜和主畫面會出現「遊戲樂園」，打開時是全螢幕、沒有網址列。長按圖示可以直接開「霓虹打磚塊」或「夜市彈珠台」。
- **iPhone / iPad**：Apple 不允許網頁一鍵安裝（Safari 沒有安裝視窗的功能），所以按鈕改叫「加到主畫面」，會顯示三步驟教學（分享 →「加入主畫面」→ 打開「以網頁 App 打開」→ 新增），並用箭頭指出分享按鈕的位置（iPhone Safari 在下方、iPad 和 Chrome 在右上角）。第一次用 iPhone 打開時下方也會跳出小提示。加好一次之後，在主畫面點圖示就是全螢幕 App，不用再開瀏覽器。
- **LINE、Facebook 內建瀏覽器**：不能安裝，按鈕會引導改用手機瀏覽器開啟（LINE 可以一鍵轉開）。
- **電腦（Chrome / Edge）**：網址列右邊的安裝圖示。

安裝後玩過的遊戲會存在手機裡，沒有網路也能玩；第一次打開首頁時會在背景預先下載所有遊戲。

效能：遊戲畫布最高用 2 倍解析度（記憶體或核心較少的手機用 1.5 倍）；兩個 3D 遊戲太卡時會自動降低畫質（解析度 → 發光 → 影子）並記住設定。安裝後的 App 打開網頁時會直接用存起來的版本（不用等網路），背景再下載新版，下次打開就是新版。

相關檔案：`manifest.webmanifest`（App 名稱、圖示、顏色）、`sw.js`（離線快取）、`assets/icons/`（App 圖示與安裝畫面截圖）。新增遊戲時不用改 `sw.js`，首頁會自動把新遊戲加進預先下載清單。

## 放到 GitHub Pages

1. 把這個專案推到 GitHub。
2. 到 repository 的 **Settings → Pages**。
3. **Source** 選 **Deploy from a branch**，Branch 選 `main`（或你的分支）和 `/ (root)`，按 **Save**。
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`（本專案為 <https://erictsau.github.io/child-games/>）。

## 在自己電腦上玩

直接用瀏覽器打開 `index.html` 就可以玩。如果想模擬網站環境，可以在資料夾裡執行：

```bash
python3 -m http.server 8000
```

然後打開 <http://localhost:8000>。

所有角色、道具和場景都是用 Canvas 和 SVG 手繪的向量圖，音效和背景音樂用 Web Audio 即時合成，沒有任何外部檔案。

夜市彈珠台、霓虹打磚塊、極速公路、夾娃娃機、極限撞球、3D 保齡球、3D 迷你高爾夫、3D 空氣曲棍球、3D 射飛鏢、3D 街頭投籃、3D 桌上足球、3D 桌球、3D 射箭、3D 極速跑酷、積木小城市、3D 滑雪和 3D 足球 PK 用 [three.js](https://threejs.org/)（MIT 授權，放在 `assets/vendor/three/`）做 3D 繪圖；夜市彈珠台在裝置不支援 3D 時會自動改用平面版 `games/night-pinball/classic.html`。

前 30 個遊戲都有標題畫面、多個關卡、1～3 顆星評分（存在瀏覽器裡），收集星星可以解鎖新角色、造型或場景。夜市彈珠台沒有關卡，一開始送 100 顆鋼珠，玩到用完為止（剩下的鋼珠會記在瀏覽器裡）。

霓虹打磚塊是比較正式的街機玩法：關卡沒有上限（第 11 關以後由程式自動產生、越來越難），進度和最高分會記在瀏覽器裡，可以從最高關卡繼續。操作：滑鼠或手指左右移動，點擊或空白鍵發球，P 鍵暫停。
